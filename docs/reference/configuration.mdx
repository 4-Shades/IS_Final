All settings are environment variables, read in `shared/config.py`. There are no settings files beyond these.

**Where values come from**

- **Self-hosted:** `.env` in the repository root, copied from `.env.example`. `run.py` and Docker Compose load it. Plain `uvicorn` needs `--env-file .env`, and `streamlit run` doesn't read it.
- **AWS:** the ECS task definitions set by Terraform, with secrets read from SSM Parameter Store when a task starts.
- **Railway:** the Flight service's variables in the Railway dashboard.
- **Streamlit Cloud:** the app's secrets, for the UI only.

## Language model

| Variable | Default | Cloud value | Description |
| --- | --- | --- | --- |
| `LLM_PROVIDER` | `ollama` | `openai` | `ollama` or `openai`. Any other value fails at the first model call. |
| `LLM_TIMEOUT_SECONDS` | `90` | `120` | How long an agent waits for one model call. |
| `OLLAMA_BASE_URL` | `http://localhost:11434` | not set | Ollama's address. Docker Compose always uses `http://ollama:11434`, ignoring `.env`. |
| `OLLAMA_MODEL` | `llama3.2:3b` | not set | Model used to generate suggestions. |
| `OLLAMA_EMBEDDING_MODEL` | `embeddinggemma` | not set | Embeds guidance passages and queries when `LLM_PROVIDER=ollama`. See [Retrieval](#retrieval). |
| `OPENAI_MODEL` | `gpt-4o-mini` | `gpt-4o-mini` | OpenAI model. |
| `OPENAI_API_KEY` | none | SSM `/travel/openai-api-key` (Stay, Activities); Railway variable (Flight) | Required when `LLM_PROVIDER=openai`. Secret. |
| `OPENAI_BASE_URL` | `https://api.openai.com/v1` | same | Any OpenAI-compatible Chat Completions endpoint. |

## Retrieval

Settings for the Wikivoyage guidance added to Flight, Stay, and Activities prompts. See [Build the guidance index](/how-to/build-the-guidance-index).

| Variable | Default | Description |
| --- | --- | --- |
| `RAG_ENABLED` | `true` | Turns retrieval on. With no index built, retrieval is skipped with one log line, so leaving it on is harmless. |
| `RAG_STORE` | `chroma` | Vector store: `chroma` (self-hosted) or `simple`, LlamaIndex's file-based store, read-only at query time (Vercel). |
| `RAG_INDEX_DIR` | `data/rag/index` | Where the index is read and written, relative to the working directory. Docker Compose mounts the `rag-index` volume there; Vercel uses the committed `data/rag/vercel`. |
| `RAG_TOP_K` | `2` | Passages retrieved per agent. Each adds prompt text, which slows CPU-only Ollama. |
| `RAG_MIN_SCORE` | `0` | Drop passages with a similarity score below this (0 to 1). |
| `RAG_TIMEOUT_SECONDS` | `30` | Give up on retrieval after this long and plan without guidance. The slow case is the first lookup after Ollama has unloaded the embedding model. |
| `OPENAI_EMBEDDING_MODEL` | `text-embedding-3-small` | Embedding model when `LLM_PROVIDER=openai`. |
| `OPENAI_EMBEDDING_DIMENSIONS` | `512` | Length of OpenAI embedding vectors. Shorter keeps the index small; `text-embedding-3` models support it. |

The embedding model follows `LLM_PROVIDER`: `OLLAMA_EMBEDDING_MODEL` for Ollama, `OPENAI_EMBEDDING_MODEL` for OpenAI. An index only works with the model, and for OpenAI the dimensions, that built it; after changing any of them, rebuild with `--rebuild`.

The ingest command, `python -m common.rag.ingest`, also takes `--store` and `--out` to override `RAG_STORE` and `RAG_INDEX_DIR`, `--destinations` for a comma-separated list instead of `data/rag/destinations.txt`, `--refresh` to re-download cached articles, and `--rebuild`.

## Service addresses and timeouts

| Variable | Default | Cloud value | Description |
| --- | --- | --- | --- |
| `FLIGHT_SERVICE_URL` | `http://localhost:8001` | Railway Flight URL | Read by the Host. |
| `STAY_SERVICE_URL` | `http://localhost:8002` | `http://stay.travel.internal:8002` | Read by the Host. |
| `ACTIVITIES_SERVICE_URL` | `http://localhost:8003` | `http://activities.travel.internal:8003` | Read by the Host. |
| `DOWNSTREAM_TIMEOUT_SECONDS` | `30` | `150` | How long the Host waits for each agent. Keep it above `LLM_TIMEOUT_SECONDS`. |
| `HOST_SERVICE_URL` | `http://localhost:8000` | the `host_public_url` Terraform output | Read by the UI. A Streamlit secret of the same name takes precedence. |
| `HOST_API_KEY` | none (Host is open) | SSM `/travel/host-api-key` (Host); Streamlit secret (UI) | When set, the Host requires it as `X-API-Key` on `POST /run`, and the UI sends it. Secret. |

The UI waits up to 180 seconds for a trip plan; this is fixed in `travel_ui.py`.

## Metrics

| Variable | Default | Description |
| --- | --- | --- |
| `OTEL_EXPORTER_OTLP_ENDPOINT` | none (export off) | Grafana Cloud OTLP endpoint. Setting it turns metrics export on. |
| `OTEL_EXPORTER_OTLP_HEADERS` | none | `Authorization=Basic%20...` from Grafana Cloud. Secret. On AWS, from SSM `/travel/otel-otlp-headers`. |

See [Metrics](/reference/metrics) for what's exported.

## Travel-data flags

`OPEN_TRAVEL_DATA_ENABLED`, `WEATHER_PROVIDER_ENABLED`, `PLACES_PROVIDER_ENABLED`, and `GROUND_TRANSPORT_ENABLED` default to `false`. They're read into the settings, but no agent checks them yet: the geocoding, places, and weather adapters in `common/travel_data.py` aren't wired into any agent. Setting them to `true` currently has no effect.
